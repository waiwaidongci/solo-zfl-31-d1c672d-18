# 手工织锦工作台

零依赖纯前端应用，直接用浏览器打开 `index.html` 即可。包含两个工作台（顶部切换，数据互不影响）：

## 纹样排版台

保留原有全部功能：

- 经纬网格绘制（单点 / 十字 / 小菱形图块、拖动连续填色）
- 用色统计、重复单元预览、断线风险提示
- 撤销 / 重做、本地保存、导出 JSON

## 织造计件结算台

- **工序计划工量**：按排版台当前纹样自动生成 4 道工序（牵经、挑花结本、上机织造、整理整修）的计划工量。
- **主数据**：维护织工、按生效日期取值的工序单价（同一工序可有多段历史价）、班次（含跨夜班）与班次津贴、节假日、节假日计件倍数、加班时基。
- **录入**：每条明细记录生产日期、上下班时段、完成量、返工量（按工序返工系数）、件数，以及最多两段加班时段。
- **自动计薪**：
  - 单价按生产日期取当天生效价；
  - 工作时间跨班次 / 跨午夜自动分段，计件工资按段内时长占比分摊，班次津贴按跨班占比计；
  - 落在节假日的计件段乘节假日倍数（返工不乘）；日常加班 2 倍、节假日加班 3 倍时基；加班与正常班次重叠直接拦截；
  - 起止时刻相同按零时长拒绝（不当 24 小时）；跨结算周期的夜班不静默裁剪——周期末日最多做到 24:00，跨入次月或首日前跨入的时段整体拒绝，需拆成两笔分别录到对应周期；班次之间时段重叠也会拦截。
- **工资单生命周期**：
  - 草稿可任意修改；确认时整单试算，通过才落库并**冻结**当时的单价、班次、节假日、加班参数和计划工量；
  - 确认后不能改正单，只能开**调整单**（正补负扣、原因必填）；
  - 重复确认、预支 / 扣款超发导致实发为负、负数录入、缺少织工、明细超计划 / 越出周期等一律拦截；任何写操作失败都整体回滚，不留半张单。
- **持久化**：工资单、调整单、明细、规则全部存 localStorage，刷新后保留。
- **导出 / 导入复核**：导出台账 JSON（含纹样与 FNV-1a 校验和）；导入时校验文件完整性，并用每张已确认单冻结的规则重新计算，与冻结金额逐分核对，保证“导出再导入复核同一结果”。
- **旧版兼容**：已确认单始终按其确认时冻结的规则复核，不套用升级后的新录入校验（如旧版允许的跨月加班、旧版相同时刻的计薪结果都保持原额，不会被判成越界）；新建单与草稿仍执行最新的周期与零时长校验。

npm test        # 计薪引擎 37 项单测（node 直接运行，含时间/锁定/旧档迁移边界回归）
